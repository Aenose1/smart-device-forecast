# SAMPLE / DEMO DATA ONLY

`sample_devices.csv` and `sample_price_history_DEMO.csv` are **synthetic**, produced by `scripts/generate_sample_data.py`.
Device names and brands are fictional and every price row has `source = SAMPLE-DEMO-SYNTHETIC`.
They are stored with `is_sample = true`; the UI and PDF reports label them as demo data.
They are NOT real market prices. Load real data via **Admin → Datasets**.
